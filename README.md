# Local LLM Sentiment Analyzer

A local Streamlit dashboard for CSV sentiment analysis and custom zero-shot text classification. It uses Ollama and Scikit-LLM, so no OpenAI API key or cloud service is required.

`CSV → Streamlit → Scikit-LLM → scikit-ollama → Ollama → Llama 3.2 → Results`

## Features

- Choose any text column, or use the default `Review` column.
- Run standard positive/negative/neutral sentiment or supply custom labels.
- Configure local model, temperature, and batch size; default: `llama3.2:3b`.
- Optional short explanations, generated by your local Ollama server.
- Metrics, distribution, optional category breakdowns, and date trends.
- Search/filter without re-running the model; download all, filtered, or Excel results.
- Data-quality flags for empty, duplicate, short, and prompt-like text.
- SQLite-backed local analysis history plus unit tests and GitHub Actions CI.

## Run

Install Python dependencies and a local Ollama model:

```bash
pip install -r requirements.txt
ollama pull llama3.2:3b
python -m streamlit run app.py
```

The sidebar also lists `llama3.2:1b` if you install it with `ollama pull llama3.2:1b`.

## CSV format

Any selected column can contain text. Other fields are preserved in downloads.

```csv
Product,Rating,Review,Date
Product X,5,"I love this product.",2026-01-10
Product Y,2,"The quality was disappointing.",2026-01-11
```

## Project structure

```text
app.py                  Streamlit entry point
src/                    Reusable application code
  app_helpers.py        CSV, export, quality, and explanation helpers
  history_store.py      Local SQLite history
data/sample_reviews.csv Example input CSV
tests/                  Unit tests
.github/workflows/      CI checks
```

Run checks locally with:

```bash
python -m unittest discover -s tests
```

`analysis_history.db` is local-only and ignored by Git.
